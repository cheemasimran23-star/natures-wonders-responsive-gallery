# Nature's Wonders — Responsive Website Assignment

A mobile-first responsive gallery built from the supplied starter project.

## Project files
- `index.html` — updated content and nine replacement images with descriptive alt text
- `css/style.css` — mobile-first CSS Grid and four media queries
- `images/` — nine nature images

## Required behaviour
- Mobile: one-column grid with a 10px gap
- Tablet (`min-width: 772px`): two columns, circular figures, final figure spans both columns
- Large screen (`min-width: 992px`): three columns, every third figure spans two columns, square corners
- Reduced motion: smooth scrolling is disabled
- Dark scheme: figures have a dark background, light yellow text and black borders

Open `index.html` in a browser and test the three viewport ranges. Also test your operating system's reduced-motion and dark-colour preferences.

Run the HTML through the W3C Markup Validation Service and the site through WAVE. External validation has not been run as part of creating this package.
